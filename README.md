# Axpert DevOps Suite

Static, GitHub Pages-ready product site for Axpert Agent and AxpertOps.

## Local preview

Serve this folder from any static web server. For the same IIS pattern used by `oci-tools`, create an IIS application or virtual directory named `axpert-devops` pointing to this folder, then open:

`http://localhost/axpert-devops/`

## GitHub Pages

1. Create a public repository named `axpert-devops` under `kumaravelmanimc`.
2. Commit the contents of this folder to the repository root.
3. In **Settings > Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. The expected site URL is `https://kumaravelmanimc.github.io/axpert-devops/`.

No pricing, credentials, connection details, or private repository content is included in the site.
